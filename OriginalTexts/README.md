# Sherlock Holmes original texts

`works/` contains 60 UTF-8 English plain-text files, one per canonical work. The filename is the stable work ID in `221B/Resources/Data`. `manifest.json` maps each work to its Gutenberg source, the unmodified source file, word count, and SHA-256 checksum.

`sources/` preserves the nine complete Project Gutenberg downloads, including their ebook headers, credits, and license text. The individual files contain extracted literary text; copies are bundled in the app for reading. Project Gutenberg's original files describe their reuse terms and jurisdictional limitations; review those terms before distributing a derivative edition.

The 1917 *His Last Bow* primary book order in the bibliography places “The Cardboard Box” second; its text is taken from Gutenberg's *Memoirs* (ebook 834), which includes that story. Gutenberg's *His Last Bow* edition (ebook 2350) contains the other seven works in a different order. The story is downloaded only once in `works/`.
